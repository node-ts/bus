# create-bus-app

`npm create @node-ts/bus-app`: scaffolds a new app from the template (#269). Read the root `CLAUDE.md` first.

- **No runtime dependencies**: `util.parseArgs` and `readline/promises` only, and `importHelpers` is off so tslib isn't needed. `bin.mjs` checks for Node 24 before it imports `dist/cli.js`. Prompts (`prompt.ts`, numbered) only run in a TTY (`CliIo.isInteractive`), and only for what isn't given; `--yes` or no TTY takes the defaults. A non-empty directory fails with `DirectoryNotEmpty`. It never installs; `next-steps.ts` prints commands for the package manager in `npm_config_user_agent`.
- **The template** (`template/`) is the private workspace package `create-bus-app-template` (`packages/**` picks it up), depending on every adapter it offers with `workspace:^`, so `pnpm build`, lint (its own tsconfig in `eslint.config.mjs`, with `node:test` calls allowed as floating), format and `check:message-types` cover it. Jest ignores it: its tests run with `node --test` on `dist` (`*.test.ts` unit, `*.integration.ts` against compose). It's published as is in the tarball (`files`, minus `template/dist`); never copy its `package.json` anywhere under `packages/`, or pnpm sees a second workspace package.
- **Options**: each transport and persistence has `template/options/<kind>/<name>.json` (`OptionManifest`: label, order, default, the template dependencies only it needs, its compose services → `compose.<service>.yaml` fragments, env vars with local and compose values) and `template/src/<kind>/<name>.ts`, which exports `createTransport(queueName)` or `createPersistence()` and imports only packages, since it's copied to `src/<kind>.ts`. In the template, `src/transport.ts`/`src/persistence.ts` re-export the defaults.
- **Scaffolding** (`create-app.ts`): copies the template except build output, `options/`, every option's files, the Dockerfiles and `package.json`; renames `_gitignore`/`_dockerignore` (npm drops dotfiles like `.gitignore` from packages); replaces `create-bus-app-template` with the project name everywhere (message names, the generated message types' keys, README), so `check:message-types` passes in the app. It writes `compose.yaml` (`include:` of the fragments, plus `provision` and `app` in the `app` profile; `build-compose-file.ts`), `.env.example` and `package.json` (`build-package-json.ts`: keeps dependencies no option lists plus the chosen options', `workspace:` → `^<version>` from `dist/versions.json`, which `tools/write-versions.mjs` writes at build time; `packageManager` for pnpm, for corepack in `Dockerfile.pnpm`). The project name is the directory's name, lowercased to `[a-z0-9_-]`, at most 50 characters so SQS queue names fit.
- **Tarballs (undocumented, CI only)**: `CREATE_BUS_APP_TARBALLS=<folder>` of `pnpm pack` output (`node tools/pack-packages.mjs <folder>` from the root) copies the `@node-ts` tarballs into the app's `tarballs/` and depends on them with `file:`, overriding them for npm (`overrides`) and pnpm (`pnpm-workspace.yaml`, since pnpm 12 ignores `pnpm.overrides` in package.json). CircleCI's `create-bus-app` job creates five apps this way and installs, builds and tests them against secondary containers (one with npm too); `create-bus-app-docker` (machine executor) runs `docker compose config` on each and builds and runs the default app's image, adding `COPY tarballs` to its Dockerfile with `sed`.
- **SQS**: the app passes its own `SQSClient`/`SNSClient` with `endpoint: AWS_ENDPOINT_URL`, since the SDK sends requests with a `QueueUrl` to the queue URL's AWS host unless the client has an explicit endpoint (the env var alone isn't enough). LocalStack is pinned to `localstack/localstack:3` (later images need an auth token); Renovate ignores its majors.
- **Tests**: `src/*.spec.ts` (builders, `runCli` with `FakeCliIo` and temp dirs), and `src/create-app.integration.ts`, which creates every combination in a temp dir with the template's `node_modules` symlinked, then runs `tsc --noEmit` and `bus generate-message-types --check` in it. After changing a template message or the workflow state, run `pnpm --filter create-bus-app-template run generate:message-types`.
- Sample domain: library loans. Don't use another messaging framework's tutorial domain (clean room).
